# 你的恋爱信号 · 你到底有多难追？

一个无需安装依赖、无需后端的中文恋爱互动风格娱乐测试。

## 使用

直接打开 `index.html` 即可使用，也可通过任意静态网站服务托管。

- 24 道情境单选题，支持上一题、修改和进度恢复
- 六维确定性计分与 0—100 难追指数
- 恋爱原型、四阶段体感与三条难追原因
- 容易把你追跑、更容易追到你及容易对你上头的人与原因
- 蓝紫粉渐变雷达图与六条横向图表
- 分享图片导出

答案仅保存于当前浏览器，不上传服务器。测试仅供娱乐与自我探索，非专业心理测评。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，并选择 main 分支的根目录。
